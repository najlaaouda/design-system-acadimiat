# Color System — Primitive Tokens

## Philosophy

Acadimiat's color palette reflects elegance and sophistication. These are **Primitive Tokens** — the raw color values that Semantic Tokens are built on top of. Used across all Acadimiat products: landing pages, dashboards, websites, and mobile apps.

> **Important — Do not use these tokens directly in components.**
> Always use Semantic Tokens in code and design.
> No Scope is applied to these variables in Figma — they serve as a reference only.
